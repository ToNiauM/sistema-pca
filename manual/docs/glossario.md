# Glossário

**PCA (Plano de Contratações Anual)**
:   A lista de tudo o que o CFC pretende contratar num ano, com o valor previsto, o mês previsto e a
    unidade responsável por cada contratação.

**Item**
:   Cada contratação prevista no PCA. Tem um número (por exemplo, **Item 69/2026** é o item 69 do
    PCA de 2026), um objeto, um valor previsto e uma situação.

**Exercício**
:   O ano a que o PCA se refere. Enquanto o exercício está **aberto**, as unidades podem fazer
    pedidos sobre os itens dele.

**Objeto**
:   A descrição do que vai ser contratado.

**Unidade organizacional (UO)**
:   A área do CFC responsável pelo item (por exemplo, uma gerência ou assessoria).

**Gelic**
:   A área de licitações e contratos do CFC, que recebe da unidade o processo de cada item para
    conduzir a contratação. O **prazo de entrega** é a data combinada para essa entrega.

**Processo SEI**
:   O processo eletrônico, no SEI, em que a contratação é instruída. O item guarda o número do
    processo e, quando disponível, a unidade em que ele está no SEI.

**Situação**
:   Em que ponto o item está: **No prazo**, **Atrasado**, **Em tramitação** ou **Concluído** (ou
    **Cancelado**, quando o item saiu do PCA). Veja [Acompanhar o andamento](areas/acompanhar.md).

**Sobrestado**
:   Item ativo cujo prazo de entrega já foi adiado mais de uma vez.

**Solicitação**
:   Um pedido da unidade, feito pelo sistema, para mudar um item (prazo, mês, valor, objeto),
    cancelá-lo ou incluir um item novo. Ganha um número no formato **N/AAAA**.

**Parte**
:   Cada pedido dentro de uma solicitação. Uma solicitação pode pedir, por exemplo, prazo e valor ao
    mesmo tempo: são duas partes, cada uma decidida separadamente.

**Alçada**
:   Quem tem o poder de decidir cada tipo de pedido: a **equipe do PCA** (prazo e mês) ou a
    **diretoria** (valor, objeto, cancelamento e inclusão).
