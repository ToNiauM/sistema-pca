{% comment %} "Copiar relatório" e "Baixar HTML" do Relatório da reunião (comum às duas cascas). Os dois partem do mesmo clone do documento (#relatorio-documento): cada elemento recebe os estilos CALCULADOS pelo navegador como estilo inline (fonte, cor, fundo, borda, alinhamento, espaçamento), as larguras das colunas viram percentuais, o logo e cada gráfico SVG viram PNG (data:); SVG marcado com data-copia="omitir" sai da cópia. Assim o SEI, o Word e o e-mail recebem o relatório com a mesma cara do PDF, sem depender do CSS do sistema. Botões ligados por data-relatorio-acao (sem JS inline além do window.print()). {% endcomment %}
