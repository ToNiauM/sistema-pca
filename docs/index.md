# PCA CFC — documentação técnica

Aplicação web que substitui a planilha de acompanhamento do Plano de Contratações Anual do CFC:
dashboards, kanban, tabela editável e histórico, do planejamento à execução contratual.

Stack: Django 5.2, SQLite, HTMX e ECharts no padrão DSGov, em Docker Compose atrás do nginx.

- [Sobre o sistema](sobre-o-sistema.md)
- [Arquitetura](arquitetura.md)
- [Operação](operacao.md) e [Deployment](deployment.md)
- [Integração com o SEI](integracao-sei-pro.md)

repositório.
